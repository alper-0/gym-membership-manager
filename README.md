# 🏋️ VitalFit - Gym Management System

A complete gym management platform with member portal, admin dashboard, and staff check-in system.

## 🌟 Features

### For Members
- ✅ User registration with email verification
- ✅ Member portal with subscription tracking
- ✅ Check-in history and statistics
- ✅ Profile management

### For Staff
- ✅ Quick member check-in system
- ✅ Real-time access verification
- ✅ Email-based member lookup

### For Administrators
- ✅ Complete dashboard with analytics
- ✅ Membership plan management
- ✅ Member subscription management
- ✅ Business insights and reports

## 🛠️ Tech Stack

### Frontend
- React 18
- React Router
- Tailwind CSS
- Lucide Icons
- Axios

### Backend
- Node.js
- Express.js
- SQLite3
- JWT Authentication
- Bcrypt
